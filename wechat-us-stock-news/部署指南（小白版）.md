# 手把手部署（不懂代码也能做）

这个程序已经做好了，每天会自动把**美股利率快讯 + 中东战况早期社媒信号**推到你的微信。
你只需要做**两件事**，加起来不到 10 分钟，之后完全不用管。

> 它跑在 GitHub 的免费云上，不用你开电脑、不用装软件。

---

## 第 1 步：拿微信收消息的「钥匙」（2 分钟）

推荐用 **Server酱**（最简单，微信扫码就能收）：

1. 微信里搜索并关注公众号 **「方糖」**
2. 按公众号提示，点链接进 `sct.ftqq.com`，用微信登录
3. 页面里有一串叫 **SENDKEY** 的字符，**复制保存好**

> 备选：如果你更想用 PushPlus，微信关注 **「PushPlus 推送加」**，进 `pushplus.plus` 登录拿到 **token**。下面填的时候换成填 `PUSHPLUS_TOKEN` 即可。两者二选一。

---

## 第 2 步：把项目放到 GitHub 上自动运行（5 分钟，跟着点）

1. 打开 [github.com](https://github.com)，用邮箱注册 / 登录
2. 点右上角 **+** → **New repository**
   - Repository name：随便填，比如 `us-stock-news`
   - 选 **Public**
   - 其它不动，点 **Create repository**
3. 进仓库后，点绿色按钮旁的 **Add file** → **Upload files**
4. 把你下载的 **`wechat-us-stock-news` 整个文件夹**拖进上传区（连文件夹一起拖）
5. 拖完后拉到页面底部，点 **Commit changes** 提交

> 上传完成后，仓库里应该能看到 `config.yaml`、`src/`、`.github/` 这些文件。

---

## 第 3 步：把钥匙填进仓库（1 分钟）

1. 进你的仓库，点上方 **Settings** → 左侧 **Secrets and variables** → **Actions**
2. 点 **New repository secret**
   - Name 填：`SERVERCHAN_SENDKEY`
   - Secret 填：你第 1 步复制的 SENDKEY
   - 点 **Add secret**

（用 PushPlus 的话，Name 填 `PUSHPLUS_TOKEN`，值填你的 token。）

---

## 第 4 步：让它跑起来 ✅

1. 回仓库，点上方 **Actions** 标签
2. 左边选工作流 **美股利率快讯推送**
3. 点 **Run workflow** → **Run workflow**（手动先跑一次）
4. 等 1 分钟左右，你的**微信就会收到第一条消息** 🎉

之后每天 **北京时间 07:30 / 12:30 / 21:30** 自动推送，你什么都不用做。

---

## 收不到消息？按这个排查

- **先看 Actions 里这次运行是不是红色失败**：点进去看日志（黄色字），常见原因：
  - 钥匙复制错了 / 多了空格 → 回第 3 步重新填
  - 仓库里 **没有** `.github/workflows/daily.yml` 这个文件 → 第 2 步没把整个文件夹传上来，重传
- **微信没关注「方糖」公众号** → Server酱 发不出去，先关注
- 想立刻再试一次：去 Actions 页面点 **Run workflow** 手动触发

---

## 想改推送时间 / 加关键词？

都在 `config.yaml` 里，**改完保存、Commit 即可**，不用碰代码：
- `schedule.times`：推送时间点（北京时间）
- `rate_keywords` / `strong_keywords`：利率相关词
- `social.war_keywords`：中东/战争相关词
- `social.sources`：想多盯几个社媒频道，在这里加
